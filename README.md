# Portfólio — Vinícius Gomes Gonçalves

Site estático em HTML, CSS e JavaScript, preparado para GitHub Pages.

## Arquivos

- `index.html` — conteúdo da página
- `css/style.css` — visual, responsividade e animações
- `js/script.js` — menu, scroll reveal, filtros e modais
- `assets/img/foto-perfil.jpg` — coloque sua foto aqui
- `assets/docs/curriculo.pdf` — coloque seu currículo aqui

## Personalização

No `index.html`, você pode alterar textos, experiências, competências, projetos, formação, e-mail e links.

### Foto
Coloque sua imagem em:
`assets/img/foto-perfil.jpg`

### Currículo
Coloque seu PDF em:
`assets/docs/curriculo.pdf`

O botão **Baixar currículo** já aponta para esse arquivo.

### LinkedIn
O endereço já está preenchido com o LinkedIn informado. Confira antes de publicar.

### GitHub
Substitua o link `https://github.com/` pelo seu perfil.

## Publicar

1. Crie um repositório no GitHub.
2. Envie todos os arquivos e pastas.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve.

Para um endereço no formato `https://seuusuario.github.io/`, crie o repositório com o nome `seuusuario.github.io`.
